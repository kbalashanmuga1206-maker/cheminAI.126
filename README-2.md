# 🧪 Molecule Studio

Simple Chemistry Laboratory built using Python.

## Features
- SMILES Validation
- 2D Molecular Structure
- Interactive 3D Visualization
- Molecular Properties
- Molecule Comparison
- PDF Report Download
- Chemistry Quiz

## Technologies
- Python
- Streamlit
- RDKit
- ReportLab
- 3Dmol.js

## Installation

```
pip install -r requirements.txt
```

## Run Application

```
streamlit run AI.py
```
